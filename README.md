# Naeem Collections — Shopify theme

Shopify upload ke liye yahi file use karein:

**naeem-collections-theme.zip**

Shopify Admin → Online Store → Themes → Add theme → Upload zip file.

Repo ke green "Code → Download ZIP" button ko Shopify mein upload mat karein. Us zip ke andar extra folder hota hai aur Shopify use reject kar deta hai.
